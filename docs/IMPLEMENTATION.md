# 实现说明

## 1. 目标与取舍

需求优先级为：轻量、纯前端、可打印、可再次编辑。实现中没有引入 React/Vue、状态管理、UI 组件库、后端或 CDN。运行时代码由原生 ES Module 组织，Three.js 负责预览与几何，`three-bvh-csg` 负责真实布尔挖孔。

生产发行版由 esbuild 打包成单个 HTML。当前 `dist/index.html` 约 **768 KB 未压缩 / 202 KB gzip**（Three.js 与 CSG 内核占主要体积），低于 1 MB 的未压缩目标。单文件可直接通过 `file://` 打开，不需要服务器。

## 2. 模块划分

| 文件 | 职责 |
| --- | --- |
| `src/app.js` | DOM 绑定、表单校验、状态更新、构建调度、导入/导出、拖拽、自动保存、提示 |
| `src/schema.js` | 默认参数、版本、范围、规范化、孔分析、预设、文件名 |
| `src/board-geometry.js` | 圆角矩形拉伸、CSG 减法、直接建模回退、水密/流形检查、体积 |
| `src/preview.js` | Three.js 场景、Z-up 相机、OrbitControls、灯光/阴影、视角切换、资源释放 |
| `src/stl-export.js` | 无依赖二进制 STL writer |
| `styles.css` | 完整界面样式与响应式布局 |
| `scripts/build.mjs` | esbuild 构建 + CSS/JS 内联到单个 HTML |
| `scripts/test-geometry.mjs` | schema、孔分析、CSG/回退和 STL writer 单元检查 |
| `scripts/test-app.mjs` | 无头浏览器端到端验收 |

## 3. 核心流程

### 参数输入

- 数字字段保存为 number，但允许用户直接输入。输入期间只接受范围内有效值。
- 无效值时模型保留上一次有效结果，同时导出按钮禁用，状态显示“参数待修正”。
- 输入框失焦时自动夹紧到合法范围。
- 每次有效的尺寸或孔参数变更进入约 48 ms 的防抖窗口，然后同步重建模型。
- 颜色和名称变更不触发几何重建。

### 模型生成

1. 用 `THREE.Shape` 生成圆角矩形轮廓；
2. `ExtrudeGeometry` 沿 Z 拉伸到指定厚度，并平移至 Z 居中；
3. 对每个有效孔生成贯穿板厚的圆柱 cutter；
4. 使用 `three-bvh-csg` 的 `SUBTRACTION` 逐个做布尔减法；
5. 焊接顶点并统计边界边、非流形边、退化三角形；
6. 通过水密检查后将几何交给预览，并允许 STL 导出；
7. 若 CSG 失败或结果不水密，回退为“轮廓直接带孔”的 ExtrudeGeometry。该回退仍生成真实贯穿孔，并对不能共存的互相重叠孔做跳过处理。

### 孔位分析

`schema.js` 使用圆角矩形的 signed distance 对孔周围 48 个采样点进行判断：

- 整圆都在板内：参与建模；
- 超出板边：提示并跳过；
- 孔与孔重叠：提示；CSG 路径仍参与建模并合并；
- 输入越界：阻止构建，直到修正。

### STL 导出

STL 由手写 writer 生成，避免额外引入导出 addon：

- 80 字节 header；
- uint32 little-endian 三角面数；
- 每面法线、三个顶点、属性；
- 直接使用当前几何坐标，单位保持毫米；
- 导出前要求当前模型水密且未处于待更新状态。

测试中会解析 STL 并重新焊接顶点，确认每条边恰好被两个三角形共享，确保切片软件能识别为封闭实体。

### 导入

- 支持点击选择和拖拽 `.board.json`；
- 文件上限 2 MB；
- 去除 BOM 后使用 `JSON.parse`；
- 拒绝根节点非对象、且既无 `board` 也无 `holes` 的 JSON；
- 缺失字段使用默认值，越界值夹紧，并显示规范化提示；
- 导入后自动适配相机并重建模型。

### 自动保存

使用 `localStorage` 保存最近一次参数，刷新/重新打开后恢复。localStorage 不可用时静默降级，不影响其他功能。

## 4. 交互与界面

- 桌面端：左侧参数/导出，右侧 3D 预览；
- 移动端：预览在上，参数在下；导出栏贴底；
- 3D 预览支持 OrbitControls 旋转、缩放、平移，双击回到立体视角；
- 提供立体、顶视、前视、右视四个视角；
- 参数更新时状态条显示水密性、越界孔或重叠孔；
- 统计信息显示外形、三角面数、实体体积和生成耗时；
- 所有关键状态通过文字提示，而不是只依赖颜色。

## 5. 验收结果

`npm test` 自动执行 78 项检查（35 项 schema/几何检查 + 43 项浏览器端检查），当前全部通过。覆盖：

- 默认模型使用 CSG 路径且水密；
- 修改尺寸后实时重建，包围盒正确；
- 安装孔添加、编辑；
- `.board.json` 导出内容完整，文件名自动生成；
- 二进制 STL 三角面数、XYZ 边界、字节长度正确；
- STL 焊接后每条边恰好属于两个三角形（封闭流形）；
- 文件导入和拖拽导入；
- 非法值阻止导出并在失焦后夹紧；
- 越界孔跳过且模型仍可打印；
- 预设载入；
- 视角切换；
- localStorage 刷新恢复；
- 移动端无横向溢出。

## 6. 范围外

- 异形多边形板；
- 自动外壳；
- 连接器占位和元件库；
- 3MF 导出；
- 云端同步或分享；
- 多用户/账号。

这些能力可以在当前 schema 与几何管线之上继续扩展，例如为 `board` 增加 `outline` 数组，或新增 `features` 数组并复用 CSG 管线。
