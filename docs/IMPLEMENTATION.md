# 实现说明

## 1. 产品方向

本项目已从“开发板本体生成器”调整为“开发板亚克力外壳生成器”：

- 开发板模型只作为内部参考和孔位来源；
- 主要输出是六块亚克力板的激光切割文件；
- 外壳使用榫卯互锁和一体化螺丝/固定柱装配；
- 开发板安装孔位同时作为外壳固定柱位置，顶板、板子和底板由同一组上下固定柱锁紧；
- 同时保留可编辑参数文件和可配置界面。

默认参数基于 85 × 56 × 1.6 mm 的树莓派 4B：

- 板材：3 mm 亚克力；
- 板边间隙：2 mm（紧凑贴合）；
- 底板净空：6 mm；
- 顶部净空：16 mm；
- 侧板外轮廓：95 × 66 × 29.6 mm；
- 顶/底板四周各外扩 3 mm，外壳外形：101 × 72 × 29.6 mm；
- 开发板 4 个安装孔位各生成一组上下固定柱，顶板和底板各 4 颗螺丝；
- 不再单独设置壳体四角角柱，固定柱本身同时承担板子支撑和外壳锁紧。

## 2. 六面板结构

### 面板布局

外壳由以下六块板组成：

| 面板 | 尺寸关系 |
| --- | --- |
| 顶板 / 底板 | 外壳宽 × 外壳深（含每边 3 mm 外沿） |
| 前面板 / 后面板 | 内腔宽 × 内腔高 |
| 左面板 / 右面板 | 侧板外轮廓深 × 内腔高 |

左/右面板跨完整侧板深度，前/后面板位于左右面板之间。顶/底板比侧板外轮廓每边大 3 mm，形成外沿。

### 榫卯

- 侧板的上/下边缘带有矩形榫舌，插入顶/底板内部的**封闭槽**；
- 封闭槽四周保留完整外沿，侧板榫舌不能横向抽出；
- 前/后面板的左右竖边带有竖向榫舌，插入左/右面板前/后边缘的榫槽；
- 榫舌宽度与数量根据面板长度自动计算；
- 榫槽宽度增加 `fit` 配合间隙，默认 0.15 mm；
- 顶/底板和侧板厚度方向都采用直榫，适合 3 mm 激光切割。

### 固定与硬件

固定柱直接复用开发板安装孔位，不再分成“外壳角柱”和“板子铜柱”两套：

- 每个有效板孔生成一组下固定柱和上固定柱；
- 下固定柱位于底板内表面与开发板底面之间，高度等于 `bottom_gap`；
- 上固定柱位于开发板顶面与顶板内表面之间，高度等于 `top_gap`；
- 顶板和底板在同一个 X/Y 坐标开过孔；
- 顶板和底板各一颗螺丝，把顶板、固定柱、开发板和底板锁成一体；
- 有效板孔不足 3 个时给出稳定性警告；
- 没有有效板孔时不会生成固定柱，并阻止形成完整壳体固定。

五金规格限制为常见公制机械螺丝：

| 规格 | 面板标准过孔 |
| --- | ---: |
| M2 | 2.4 mm |
| M2.5 | 2.9 mm |
| M3 | 3.4 mm |
| M4 | 4.5 mm |

- 界面通过下拉框选择规格，不再允许任意过孔直径；
- 导入旧文档时，非标准过孔会归一到最接近的标准规格并给出警告；
- BOM 同时列出规格、标准过孔、六角固定柱和螺丝长度；
- 若开发板孔径明显小于当前规格，界面会提示扩孔或改用更小的标准规格。

3D 预览中的固定柱使用六角金属柱，不生成螺纹细节；8 颗面板螺丝使用无沉头锥面的平头造型，头部外缘做圆角过渡，顶面显示六角槽，并生成穿过亚克力面板、进入固定柱的螺纹螺杆。DXF 不包含五金。

## 3. 接口与通风

### 接口开孔与 2D 侧板编辑器

- 支持前面板、后面板、左面板、右面板，四个侧板可独立切换；
- 支持矩形和圆形；
- `U/V` 坐标以当前侧板中心为原点，U 向观察者右侧，V 向上；
- 左侧板/右侧板在装配坐标中镜像，但 U 始终按面板自身视图保持向右；
- 提供毫米网格、中心轴、安全边距和当前板尺寸；
- 可以直接拖动开孔，拖动时同步更新 U/V 数值，释放鼠标后重建模型；
- 内置 USB-C、USB-A、HDMI、RJ45、DC 5.5 和 3.5 mm 音频孔预设；
- 开孔列表只显示当前选中的侧板，其他侧板以数量标记；
- 开孔互相重叠时跳过后一个并产生警告；
- 越界开孔会被跳过，并在状态栏和场景提示中说明。

### 通风槽

- 顶板和底板同时生成；
- 根据槽数量、宽度、长度自动居中；
- 使用圆角长槽；
- 自动避开顶/底板上的固定柱过孔；
- 面板尺寸不足时减少槽数或跳过冲突槽，并给出警告。

## 5. 几何实现

### 面板轮廓

每块面板使用一个封闭的二维多边形轮廓，再加内部孔洞：

- 基础矩形；
- 边缘矩形榫舌使用正向外偏移；
- 边缘榫槽使用负向内偏移；
- 顶/底板的侧板槽是内部闭合矩形孔，四周保留外沿；
- 开孔和通风槽是内部闭合路径；
- 轮廓和孔洞同时用于 `ExtrudeGeometry` 与向量导出。

每块挤出后的面板都经过焊接顶点检查，当前默认模型六块板均为水密实体。

### 装配变换

- 顶/底板用 XY 平面拉伸，再平移到对应 Z；
- 前后板使用 XZ 平面，左右板使用 YZ 平面；
- 不同面板使用正交基矩阵转换到世界坐标；
- 预切割几何在生成时直接烘焙到装配位置，便于预览；
- 爆炸视图通过每块面板的装配方向偏移实现，不修改切割数据。

### 开发板参考

开发板继续使用原模型管线：

1. 圆角矩形拉伸；
2. `three-bvh-csg` 真实布尔挖孔；
3. 水密性检查；
4. 将模型放到外壳内腔对应高度。

开发板有效安装孔同时生成上下两段固定柱，以及顶板和底板上的同轴过孔。相邻过近的板孔会跳过重复固定柱并产生警告。

开发板参考几何按板尺寸、厚度、圆角和孔位生成缓存键。修改外壳净空、板厚、通风或接口时复用缓存的板子几何，避免重复执行 CSG；只有板子的尺寸或孔位变化时才重新生成。

侧板开孔之间会做保守的包围盒重叠检测，重叠的第二个开孔会被跳过并提示，避免导出相交的激光切割路径。

## 6. 导出

### DXF

- ASCII DXF R12，`$ACADVER = AC1009`；
- `$INSUNITS = 4`，单位毫米；
- 包含 HEADER、TABLES、BLOCKS、ENTITIES 四个标准 section；
- TABLES 中定义 `CONTINUOUS` 线型、`0 / CUT / ANNOTATION` 图层和 `STANDARD` 文字样式；
- 所有切割路径在 `CUT` 图层，使用闭合 POLYLINE；
- 六个面板排在一张切割图上，之间留有间距；
- `ANNOTATION` 图层包含图纸标题、幅面尺寸、板材厚度、1:1 比例、图层说明；
- 每个面板都有独立文本标注，例如 `TOP 101 x 72 mm`；
- 文本使用 ASCII 和 `STANDARD` 样式，避免 R12 中文编码兼容问题；
- 不包含 kerf 补偿，由激光软件处理。

### SVG

- 与 DXF 相同的面板排布；
- `width`/`height` 使用毫米；
- 用组合并每块面板的轮廓和孔洞路径；
- 主要用于预览、排版检查和 SVG 工作流。

### 参数文件

- 版本 2，`format: boardforge-case`；
- 支持旧 `.board.json` 自动迁移；
- 支持拖拽导入；
- 主题、深浅色、投影和自动保存开关保存在 `localStorage`，不写入参数文件。

### 切割排版预览

界面中的「排版预览」会打开一个 2D 弹窗，显示六块面板在切割图上的位置、总幅面尺寸和实际切割路径。它使用与 DXF/SVG 相同的排布逻辑，便于在下载前确认板材尺寸和排版。

### 五金清单

「一体固定柱」区域提供动态 BOM：

- 亚克力板数量与厚度；
- 上下固定柱数量与长度；
- 面板螺丝数量和推荐长度区间；
- 垫圈建议；
- 板孔与固定柱过孔的兼容性提示。

BOM 可一键复制为文本，方便采购或装配记录。

### 项目库

- 启动时打开项目库弹窗，可选择继续当前草稿、从预设新建、打开已保存项目或导入参数文件；
- 顶栏提供「保存」和「项目」入口；
- 项目库保存在 `localStorage` 的 `boardforge.projects.v1`，最多 50 个项目；
- 每个项目保存完整参数文档、名称、创建时间和更新时间；
- 「保存当前项目」会创建新项目或更新当前关联项目；
- 项目可以打开、删除；删除当前项目时，工作区会保留为草稿；
- 当前活动项目 ID 保存在 `boardforge.active-project.v1`；
- 日常编辑仍自动保存到单项目草稿；项目库是显式保存的多项目副本。

### 项目替换保护

草稿自动保存只保留当前工作区。点击开发板预设、新建或打开另一个项目时：

- 如果当前状态只是初始默认值、某个未修改的预设，或已经存在于项目库且没有修改，直接切换，不额外打断；
- 如果当前项目已经自定义且未保存，会打开确认弹窗，列出当前项目名称、开发板尺寸、孔位/开孔数量和外壳外形；
- 可以选择取消、直接替换，或先导出 `.case.json` 再继续；
- 导出失败或当前参数无效时不会继续替换；
- 弹窗支持点击背景、关闭按钮和 Escape 取消，并恢复原来的键盘焦点。

### 设置面板

顶栏的「设置」按钮打开一个弹窗，集中管理本机界面偏好：

- 外观：深色 / 浅色分段切换；
- 主题色：7 个预设、自定义取色和当前色值预览；
- 三维预览：透视 / 正交投影，与 3D 工具栏的投影按钮双向同步；
- 草稿：自动保存开关，关闭时会清除本地草稿，已保存项目库不受影响；
- 「全部恢复默认」一次性重置深色、默认主题色、透视投影和自动保存；
- 弹窗支持点击背景、关闭按钮、完成按钮和 Escape 关闭，并恢复原来的键盘焦点。

### 侧边栏折叠模块

- 项目名称和开发板预设始终可见，不参与折叠；
- 「外壳尺寸」「固定散热」「接口开孔」「板型参考」使用原生 `<details>/<summary>`；
- 一次最多展开一个主要模块，打开新模块会自动收起旧模块；
- 折叠标题保留关键摘要：外形尺寸、固定柱与通风数量、开孔数量、板子尺寸与孔数；
- 表单控件只是隐藏，不销毁，因此折叠不会丢失用户输入；
- 输入非法参数时自动展开所在模块，并滚动到该模块；
- 展开模块会滚动到侧边栏可视区域顶部；
- 支持键盘操作和 `prefers-reduced-motion`，减少动画偏好下不使用平滑滚动。

## 7. 预览与交互

- 透明亚克力材质 + 发光边线；
- 深色/浅色模式下自动调整面板颜色、网格和阴影；
- 透视投影和正交投影切换，切换时保持相机方向、目标点和视觉尺度；
- 正交相机使用独立视锥和 OrbitControls，偏好保存在本机；
- 视角控件压缩为「立体 / 顶视 / 侧视」三段，前/后/左/右四个正视角收进侧视菜单；
- 侧视菜单支持点击外部关闭、Escape 关闭和方向键切换，选择后自动收起；
- 侧视按钮显示当前侧视方向；从开孔编辑器切换侧板时，按钮会同步更新；
- 顶视或侧视下用鼠标拖动旋转时，模型进入自由立体状态，工具栏的「立体」同步激活；
- 顶视使用 Y 轴作为相机 up，拖动前会同步 OrbitControls 的缓存轴，避免顶视无法旋转；
- 前后左右视角方向严格垂直于对应侧板，适合配合正交投影设置接口开孔；
- 视角切换沿围绕模型中心的圆弧运动；前后/左右 180° 切换使用 620 ms 环绕动画，避免穿过模型中心；
- 爆炸视图；
- 固定柱端面轻微嵌入开发板，地面网格与阴影平面拉开距离，避免相机阻尼移动时出现共面闪烁；
- 开发板参考模型显示在内腔中；
- 状态栏显示面板数、警示数量和导出状态；
- 移动端预览在上，参数在下，导出栏固定在底部。

## 9. 已知限制

- 只有矩形六面盒，不支持斜面、异形外轮廓；
- 多项目库保存在浏览器 `localStorage`，清除站点数据会丢失，重要项目应导出 `.case.json`；
- 开孔需要用户手动定位，没有板级连接器自动识别；
- 激光 kerf 和亚克力实际厚度会影响榫卯配合，应切割测试件；
- 固定柱和螺丝是标准五金，尺寸为视觉近似；
- 一体化固定柱要求开发板安装孔能穿过对应螺柱/螺丝，板孔过小时需要扩孔或改小过孔；
- DXF/SVG 仍是名义尺寸，未自动做 kerf 偏置；切割排版只显示幅面，不按具体激光机自动旋转/重排；
- 未实现 3MF、带尺寸标注的工程图、供应商采购链接或云端存储。
