# 实现说明

## 1. 产品方向

本项目已从“开发板本体生成器”调整为“开发板亚克力外壳生成器”：

- 开发板模型只作为内部参考和孔位来源；
- 主要输出是六块亚克力板的激光切割文件；
- 外壳使用榫卯互锁和一体化螺丝/固定柱装配；
- 开发板安装孔位同时作为外壳固定柱位置，顶板、板子和底板由同一组上下固定柱锁紧；
- 同时保留 STL 装配预览、可编辑参数文件和深浅色界面。

默认参数基于 85 × 56 × 1.6 mm 的树莓派 4B：

- 板材：3 mm 亚克力；
- 板边间隙：2 mm（紧凑贴合）；
- 底板净空：6 mm；
- 顶部净空：16 mm；
- 外壳外形：95 × 66 × 29.6 mm；
- 开发板 4 个安装孔位各生成一组上下固定柱，顶板和底板各 4 颗螺丝；
- 不再单独设置壳体四角角柱，固定柱本身同时承担板子支撑和外壳锁紧。

## 2. 六面板结构

### 面板布局

外壳由以下六块板组成：

| 面板 | 尺寸关系 |
| --- | --- |
| 顶板 / 底板 | 外壳宽 × 外壳深 |
| 前面板 / 后面板 | 内腔宽 × 内腔高 |
| 左面板 / 右面板 | 外壳深 × 内腔高 |

左/右面板跨完整外壳深度，前/后面板位于左右面板之间，所有外表面齐平。

### 榫卯

- 侧板的上/下边缘带有矩形榫舌，插入顶/底板边缘的开口槽；
- 前/后面板的左右竖边带有竖向榫舌，插入左/右面板前/后边缘的榫槽；
- 榫舌宽度与数量根据面板长度自动计算；
- 榫槽宽度增加 `fit` 配合间隙，默认 0.15 mm；
- 顶/底板和侧板厚度方向都采用直榫，适合 3 mm 激光切割。

### 固定与硬件

固定柱直接复用开发板安装孔位，不再分成“外壳角柱”和“板子铜柱”两套：

- 每个有效板孔生成一组下固定柱和上固定柱；
- 下固定柱位于底板内表面与开发板底面之间，高度等于 `bottom_gap`；
- 上固定柱位于开发板顶面与顶板内表面之间，高度等于 `top_gap`；
- 顶板和底板在同一个 X/Y 坐标开过孔；
- 顶板和底板各一颗螺丝，把顶板、固定柱、开发板和底板锁成一体；
- 有效板孔不足 3 个时给出稳定性警告；
- 没有有效板孔时不会生成固定柱，并阻止形成完整壳体固定。

若开发板孔径明显小于固定柱过孔，界面会在“一体固定柱”区域提示扩孔或减小过孔/五金规格。

固定柱和螺丝是标准五金件，不出现在 DXF 中，只出现在 3D 预览和装配 STL 中。

## 3. 接口与通风

### 接口开孔

- 支持前面板、后面板、左面板、右面板；
- 支持矩形和圆形；
- `U/V` 坐标以侧板中心为原点；
- 矩形孔使用圆角内角；
- 自动验证开孔是否在面板可加工区域内；
- 越界孔会被跳过，并在状态栏和场景提示中说明；
- 后面板和右面板在装配坐标中镜像，但参数使用面板自身坐标。

### 通风槽

- 顶板和底板同时生成；
- 根据槽数量、宽度、长度自动居中；
- 使用圆角长槽；
- 自动避开顶/底板上的固定柱过孔；
- 面板尺寸不足时减少槽数或跳过冲突槽，并给出警告。

## 5. 几何实现

### 面板轮廓

每块面板使用一个封闭的二维多边形轮廓，再加内部孔洞：

- 基础矩形；
- 边缘矩形榫舌使用正向外偏移；
- 边缘榫槽使用负向内偏移；
- 顶/底板边缘的槽是开口槽；
- 开孔和通风槽是内部闭合路径；
- 轮廓和孔洞同时用于 `ExtrudeGeometry` 与向量导出。

每块挤出后的面板都经过焊接顶点检查，当前默认模型六块板均为水密实体。

### 装配变换

- 顶/底板用 XY 平面拉伸，再平移到对应 Z；
- 前后板使用 XZ 平面，左右板使用 YZ 平面；
- 不同面板使用正交基矩阵转换到世界坐标；
- 预切割几何在生成时直接烘焙到装配位置，便于预览和 STL 合并；
- 爆炸视图通过每块面板的装配方向偏移实现，不修改切割数据。

### 开发板参考

开发板继续使用原模型管线：

1. 圆角矩形拉伸；
2. `three-bvh-csg` 真实布尔挖孔；
3. 水密性检查；
4. 将模型放到外壳内腔对应高度。

开发板有效安装孔同时生成上下两段固定柱，以及顶板和底板上的同轴过孔。

## 6. 导出

### DXF

- ASCII DXF R12；
- 单位毫米；
- HEADER、TABLES、ENTITIES 三个 section；
- 所有切割路径放在 `CUT` 图层；
- 六个面板排在一张切割图上，之间留有间距；
- 轮廓、开孔、通风槽都用闭合 POLYLINE；
- 不包含 kerf 补偿，由激光软件处理。

### SVG

- 与 DXF 相同的面板排布；
- `width`/`height` 使用毫米；
- 用组合并每块面板的轮廓和孔洞路径；
- 主要用于预览、排版检查和 SVG 工作流。

### STL 装配

- 合并六块面板、上下两段一体固定柱和顶/底螺丝头的三角面；
- 用于 3D 装配预览；
- 不是单体可打印模型；
- 不包含开发板参考模型；
- 文件为二进制 STL，单位毫米。

### 参数文件

- 版本 2，`format: boardforge-case`；
- 支持旧 `.board.json` 自动迁移；
- 支持拖拽导入；
- 主题和深浅色模式保存在 `localStorage`，不写入参数文件。

## 7. 预览与交互

- 透明亚克力材质 + 发光边线；
- 深色/浅色模式下自动调整面板颜色、网格和阴影；
- 立体、顶视、前视、右视四个视角；
- 爆炸视图；
- 开发板参考模型显示在内腔中；
- 状态栏显示面板数、警示数量和导出状态；
- 移动端预览在上，参数在下，导出栏固定在底部。

## 9. 已知限制

- 只有矩形六面盒，不支持斜面、异形外轮廓；
- 开孔需要用户手动定位，没有板级连接器自动识别；
- 激光 kerf 和亚克力实际厚度会影响榫卯配合，应切割测试件；
- 固定柱和螺丝是标准五金，尺寸为视觉近似；
- 一体化固定柱要求开发板安装孔能穿过对应螺柱/螺丝，板孔过小时需要扩孔或改小过孔；
- STL 装配不是可打印单体；
- 未实现 3MF、工程图、采购清单或云端存储。
